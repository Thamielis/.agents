# Agent Skill Usage Memory

For PSArchitecture continuation work, when the user explicitly invokes the
Superpowers plugin together with `continual-learning` and `self-improving-agent`,
load and apply those skills before implementation work.

Use the Superpowers guidance as the process frame, then apply the repository
instructions from `AGENTS.md`, `.github/collections/project-planning.collection.yml`,
and `.github/agents/implementation-plan.agent.md`.

When the user asks to remember this usage, keep the record repo-local in
`.github/instructions/` or the active implementation plan. Do not depend on
central session memory being writable.
